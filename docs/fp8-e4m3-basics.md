# FP8 E4M3 表示能力分析

> Phase 3 Sprint 3.1a — 量化分析，为 FP8 FFT kernel 设计提供数据基础
> 参考: Micikevicius et al. (2022) "FP8 Formats for Deep Learning"

---

## 1. E4M3 格式定义

```
┌─────┬───────┬─────────────────────┐
│ S   │ E[3:0]│ M[2:0]              │
│ 1b  │ 4b    │ 3b                  │
└─────┴───────┴─────────────────────┘
```

**解码规则**（OCP/NVIDIA 标准）:

| 条件 | 值 |
|------|-----|
| `E > 0` (normal) | `(-1)^S × 2^(E-7) × (1 + M/8)` |
| `E = 0` (subnormal) | `(-1)^S × 2^(-6) × (M/8)` |
| `E=15, M=7` | NaN（无 ±Inf） |
| `E=15, M∈{0..6}` | Normal（标准不同于 IEEE binary16） |

**关键区别**: 与 IEEE 754 不同，E4M3 将 `E=15` 用于表示 normal 值（而非 Inf），仅 `(15, 0b111)` 编码为 NaN。这扩展了动态范围 ~2×。

## 2. 关键数值

### 2.1 极值表

| 量 | 公式 | 值 | 备注 |
|----|------|-----|------|
| max normal | (1 + 6/8) × 2^(15-7) | **448** | E=15, M=6 |
| min normal | 1.0 × 2^(1-7) | **0.015625** = 2^(-6) | E=1, M=0 |
| max subnormal | (7/8) × 2^(-6) | **0.013672** | E=0, M=7 |
| min subnormal | (1/8) × 2^(-6) | **0.001953** = 2^(-9) | E=0, M=1 |
| zero | — | **0** | E=0, M=0 |
| NaN | — | — | E=15, M=7 |

### 2.2 尾数精度

```
mantissa bits = 3
ulp at 1.0    = 2^(-3) = 0.125 = 12.5%
min relative error per operation ≈ ulp/2 = 6.25%
```

这意味 **每个 FP8 乘法操作自带 ±6.25% 的相对误差**——对于 FFT 这种由 log₂(N) 层蝶形组成的算法，这是一个严峻的挑战。

### 2.3 动态范围

| 精度 | max normal | min subnormal | 动态范围 (max/min normal) |
|------|-----------|---------------|--------------------------|
| FP32 | 3.4 × 10^38 | 1.4 × 10^(-45) | ~2.8 × 10^76 (≈ 2^254) |
| FP16 | 65504 | 5.96 × 10^(-8) | ~1.1 × 10^9 (≈ 2^30) |
| BF16 | 3.4 × 10^38 | 1.4 × 10^(-45) | ~2.8 × 10^76 (≈ 2^254) |
| **FP8 E4M3** | **448** | **0.00195** | **28,672** (≈ 2^14.8) |
| FP8 E5M2 | 57344 | 1.5 × 10^(-5) | ~3.8 × 10^9 (≈ 2^32) |

**关键观察**:
- FP8 E4M3 的动态范围仅 14.8 个二进制数量级——任何值域跨越超过此范围的信号都会溢出或下溢
- FP8 E5M2 有更大的动态范围（E5M2 用于梯度），但尾数仅 2 位，精度更差——不适合 FFT
- **E4M3 是 FFT 的正确选择**（前向需要精度，而非范围）

## 3. FFT 值域分析

### 3.1 无归一化 FFT

对于输入 `x[n]` 满足 `|x[n]| ≤ 1`，FFT 输出：

```
|X[k]| = |Σ x[n] × W^(nk)| ≤ Σ |x[n]| × |W^(nk)| = Σ 1 = N
```

峰值可达 **N**（全 1 信号，DC bin）。

### 3.2 不同 N 的峰值 vs FP8 上限

| N | FFT 峰值 (max) | 超出 FP8 上限? | 安全裕度 |
|---|---------------|---------------|---------|
| 16 | 16 | ✅ | 28× |
| 32 | 32 | ✅ | 14× |
| 64 | 64 | ✅ | 7× |
| 128 | 128 | ✅ | 3.5× |
| 256 | 256 | ✅ | 1.75× |
| 512 | 512 | ❌ **溢出** | — |
| 1024 | 1024 | ❌ **溢出** | — |
| 4096 | 4096 | ❌ **溢出** | — |
| 65536 | 65536 | ❌ **溢出** | — |

**结论**: 不归一化时，N > 256 必定溢出到 FP8 最大值 448。

### 3.2 有归一化 (1/N) FFT

使用 `norm="forward"` (1/N scaling):

```
|x[n]| ≤ 1 → |X[k]| ≤ 1
```

所有 N 均安全。但精度问题转移到小值：信号幅值 1/N 量级的 bin 可能 underflow 到 0。

### 3.3 中间蝶形值的范围

这是关键但容易被忽略的点。**蝶形运算的中间结果**也需要适配 FP8 范围。

对于 DIT FFT，第 s 层蝶形处理的点对间距为 2^s。在未归一化情况下：

- 早期层（s 小）：值域约为 [−2, 2]（相邻点加减）
- 后期层（s 接近 log₂(N)）：值域增长到 O(N)（全信号贡献）

**块浮点方案的关键洞察**：每层蝶形可以有不同的共享指数，正好匹配每层的值域增长。

## 4. 精度-范围权衡

```
          精度 →                         范围 →
  E5M2  [▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓]    大（用于梯度）
  E4M3  [▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓]    中（用于前向）
  
  对于 FFT: E4M3 是正确的选择
  ─────────────────────────────────
  FFT 蝶形运算: 每次乘加 ≈ ±6.25% 误差
  需要: 较大的 mantissa → E4M3 (3-bit mantissa)
  不需要: E5M2 的宽范围 → FFT 输入通常 bounded
```

### 4.1 FP8 下不同操作的理论 SNR

| 操作 | FP8 ulp | 单操作相对误差 |
|------|---------|---------------|
| 乘法 (a×b) | 0.125 | ~6.25% |
| 加法 (a+b) | 0.125 | 取决于 |a+b| 的相对大小 |
| 乘加 (a + w×b) | 0.125 | ~9-12%（误差累积） |

对于 N 点 FFT，共 (N/2)·log₂(N) 次蝶形运算，每次含 1 次复数乘法 + 2 次复数加法 ≈ 6 次 FP8 实数运算。

## 5. 对 FFT 设计的启示

1. **必须归一化**: 未归一化 FFT 在 N > 256 时必然溢出，归一化 (1/N) 是必需的
2. **值域管理是核心**: 中间蝶形值的范围跨越 O(log₂N) 数量级，需要主动管理
3. **块浮点最优**: 每层蝶形共享一个指数 = log₂(N) 个指数管理 N 个值，开销最小
4. **N ≤ 4096 是 sweet spot**: 太小无实用价值，太大精度损失超过容忍度
5. **E4M3 >> E5M2**: FFT 是精度密集型运算，E4M3 的 3-bit mantissa 已经是最低要求

## 6. 硬件支持

| GPU 架构 | FP8 支持 | 备注 |
|----------|---------|------|
| H100 (SM_90) | ✅ 原生 FP8 tensor core | FP8→FP16 累加 |
| RTX 4090 (SM_89) | ✅ 原生 FP8 | Ada Lovelace |
| **RTX 5070 Ti (SM_120)** | ✅ 原生 FP8 | Blackwell, 完整 FP8 支持 |
| A100 (SM_80) | ❌ 无 FP8 | 需软件模拟 |

**我们的硬件 (RTX 5070 Ti, Blackwell SM_120) 有完整 FP8 原生支持**，包括 FP8 tensor core 和 FP8 寄存器操作。
