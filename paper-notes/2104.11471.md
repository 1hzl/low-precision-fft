# arXiv:2104.11471 — Li, Cheng, Lin (2021-04)

## "tcFFT: Accelerating Half-Precision FFT through Tensor Cores"

**作者**: Binrui Li, Shenggan Cheng, James Lin
**平台**: NVIDIA V100 + A100

---

## 核心思路

将 FFT 的 merge stages 重新表述为矩阵乘法，利用 NVIDIA Tensor Cores 的 FP16 算力。

- 传统 FFT 蝶形运算不是矩阵乘法 → Tensor Core 无法直接用
- tcFFT 的关键创新：single-element manipulation on Tensor Core fragments
- 精细的数据排列设计匹配 GPU memory access pattern

## 结果

| GPU | 比 cuFFT 加速 |
|---|---|
| V100 | 1.29× – 3.24× |
| A100 | 1.10× – 3.03× |

## 局限

- FP16 精度: ~35 dB（远低于 Bergach 论文的 56-61 dB）
- 不支持 autograd
- 不是 drop-in replacement

## 对我们项目的参考价值

- 用作 FP16 FFT 性能的上界参考
- 我们的 cuFFT 封装路径 (1.4-2.8x) 与之可比
- tcFFT 的 Tensor Core 映射可作为 Phase 4 优化方向
