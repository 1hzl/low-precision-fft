## 逐文件分析

### `lowp_fft/csrc/cufft_fp16.cu` — CUDA 扩展

- ✅ Plan cache (double-checked locking): 并发控制正确，race-lose 分支正确释放资源
- ✅ 错误处理完善，CUFFT_CHECK/CUDA_CHECK 宏含文件和行号
- ✅ IFFT 归一化逻辑正确（backward=1/N，与 __init__.py 的 norm 分支配合无误）
- [MAJOR] Plan cache 无淘汰策略 — 每次新 (n, batch) 组合创建新 plan，永不释放。Phase 3 FP8 大量不同尺寸可能导致 GPU 内存泄漏。建议加 LRU cap 或全量清空保护
- [MINOR] `div_` 原地归一化无副作用（output 是新创建的 empty_like），但应标注

### `lowp_fft/_autograd.py` — 自动微分

- ✅ backward 公式正确: backward(FFT) = conj(FFT(conj(grad)))
- ✅ FP32 回退有明确文档说明（stream 兼容性问题）
- ✅ 保存 ctx._saved_n 避免从 tensor shape 读取
- [MINOR] gradcheck 仅用 N=8 — 太小，无法验证大尺寸梯度稳定性

### `lowp_fft/__init__.py` — Python API

- ✅ 免转换路径（方案A）: dtype 检查避免无效 .to()
- ✅ no_grad 快速通道（方案B）: is_grad_enabled() 绕过 autograd context
- ✅ norm 三种模式的正交/前向归一化逻辑正确
- [MAJOR] fp16 静默回退 — 当 n is not None 或 dim != -1 时，用户代码走到 torch.fft.fft(input_half) 而不是报错/warning
- [MAJOR] fft() 和 ifft() 高度重复 — ~130 行几乎镜像
- [MINOR] bf16 路径做了 FP32 计算再 cast 回来，性能收益微弱
- [NIT] _ensure_dtype 死代码 — 定义了但未被调用

### `tests/test_autograd.py` — 测试

- ✅ 覆盖 forward shape/dtype/finite、backward shape/finite、gradcheck、梯度对比、roundtrip
- [MAJOR] 缺失测试: norm 模式、n padding、dim 参数、bf16 路径、非 CUDA fallback、边界值（N=1, 空 tensor）
- [MAJOR] gradcheck tolerance 过宽: eps=1e-1（标准 1e-6），可能漏检梯度错误

### `setup.py` / 构建

- ✅ CUDAExtension + BuildExtension 标准模式
- ✅ arch=sm_120 匹配 RTX 5070 Ti
- [NIT] CUDA_HOME 硬编码 Windows 路径

## 结论: 有条件通过

修完 4 个 MAJOR 后入 Phase 3。

### 解决方案

**修复 1 — fp16 静默回退**: 在 fallback 前加 `warnings.warn(f"cuFFT FP16 extension does not support n={n}, dim={dim}; falling back to torch.fft. Use n=None, dim=-1 for native FP16 acceleration.", UserWarning)`

**修复 2 — 去重**: 提取 `_fp16_fft_impl(input_half, n, dim, norm, direction)` 统一处理，fft()/ifft() 变成薄层

**修复 3 — 补测试**: 新增 ~10 个测试（norm="ortho"/"forward"、N=1、n padding、dim 参数、bf16、非 CUDA fallback）

**修复 4 — gradcheck tolerance**: eps: 1e-1 → 1e-2，同时扩大输入到 N=32

**修复 5 (minor) — plan cache**: 加 `kMaxCacheEntries=64` 上限，超出时全量清空

**修复 6 (minor) — bf16**: docstring 标注"FP32 计算 + bf16 cast，内存带宽节省，无计算加速"

**修复 7 (minor) — dead code**: 删除 `_ensure_dtype`

**修复 8 (nit) — CUDA_HOME**: README/BUILD.md 标注 Linux 环境变量设置
