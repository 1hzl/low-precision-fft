## N 衰减趋势 (ASCII 文字图)

### FP16

```
N=256    N=512    N=1024   N=2048   N=4096
  |        |        |        |        |
uniform:  61.3 --- 60.6 --- 59.9 --- 59.3 ------- 56.5   ← 衰减, N=4096 骤降 ~3 dB
normal:   61.6 --- 60.8 --- 60.1 --- 59.5 ------- 56.5   ← 衰减, N=4096 骤降 ~3 dB
multitone:61.6 --- 60.8 --- 60.0 --- 59.5 ------- 56.5   ← 衰减, N=4096 骤降 ~3 dB
impulse:* 424.1 → 427.1 → 430.1 → 433.1 → 436.1         ← 退化, N 越大 SQNR 越高
```

**FP16 趋势**: N=256→2048 每倍衰减 ~0.5–0.7 dB, N=4096 衰减加速 (~3 dB),
仅发生于 uniform/normal/multitone — 系 mantissa 10+1 位开始溢出。

### BF16

```
N=256    N=512    N=1024   N=2048   N=4096
  |        |        |        |        |
uniform:  53.1 --- 53.0 --- 53.1 --- 53.1 --- 53.1      ← 平坦, 无明显衰减
normal:   54.5 --- 54.4 --- 54.4 --- 54.4 --- 54.4      ← 平坦, 波动 < 0.1 dB
multitone:53.5 --- 53.4 --- 53.4 --- 53.5 --- 53.4      ← 平坦, 波动 < 0.1 dB
impulse:* 424.1 → 427.1 → 430.1 → 433.1 → 436.1         ← 退化
```

**BF16 趋势**: 所有信号类型 SQNR 几乎恒定, N 增大不衰减。
宽指数域 (8-bit exponent) 保证中间累加不溢出。

### BFP FP8

```
N=256    N=512    N=1024   N=2048   N=4096
  |        |        |        |        |
uniform:  22.1 --- 21.6 --- 21.2 --- 20.8 --- 20.4      ← 微降, ~0.5 dB/倍
normal:   22.5 --- 22.0 --- 21.5 --- 21.0 --- 20.7      ← 微降, ~0.5 dB/倍
multitone:23.4 --- 22.9 --- 22.4 --- 22.1 --- 21.9      ← 缓降, 仅有 ~1.5 dB 总衰减
impulse:* 424.1 → 427.1 → 430.1 → 433.1 → 436.1         ← 退化
```

**BFP FP8 趋势**: 随 N 增大轻微衰减, 每倍 ~0.4–0.5 dB。
multitone 对 N 最不敏感 (总衰减仅 ~1.5 dB, 其他约 ~1.7 dB),
因共享指数减少了多音干扰场景下的量化误差。

## 关键发现

### 1. 精度层级

| 精度 | SQNR 范围 | N 衰减特性 |
|------|----------|-----------|
| FP16 | 56.5–61.6 dB | 有衰减, N≥4096 加速 |
| BF16 | 53.0–54.5 dB | 无衰减, 全 N 平坦 |
| BFP FP8 | 20.4–23.4 dB | 微衰减, ~0.5 dB/倍 |

### 2. 信号类型影响

- **multitone > uniform/normal** — 在所有三种精度中保持一致。
  多音信号的能量分散减少了 catastrophic cancellation。
- **uniform ≈ normal** — 两者 SQNR 非常接近 (差异 < 1 dB), 说明误差主要由精度决定, 与分布形状弱相关。

### 3. BF16 的宽指数域优势

BF16 的 8-bit exponent 使 SQNR 完全不随 N 衰减, 与 FP16 (5-bit exponent)
形成鲜明对比。这是 block-circulant adapter 论文选择 BF16 的理论支撑 —
对大 N 的矩阵乘/FFT, BF16 不会像 FP16 那样在 N≥4096 时性能恶化。

### 4. BFP FP8 的共享指数收益

multitone 在 BFP FP8 下衰减最缓 (总衰减 ~1.5 dB vs ~1.7 dB), 表明
block floating-point 的共享指数机制对多音信号的量化误差有额外的抑制作用 —
当块内样本动态范围接近时, 共享指数避免了逐样本的精度浪费。

### 5. impulse 退化说明

impulse 信号在所有精度和所有 N 下给出相同 SQNR (424–436 dB),
这是退化 case — 单非零样本的 FFT 无累加舍入误差, SQNR 由纯能量公式
10·log₁₀(3N) 决定。实际使用中不可依赖此值。
